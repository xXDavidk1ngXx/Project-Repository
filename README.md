### 🔗 Smart Contracts & Web3 dApp

**Decentralized Rental Contract Platform**  
Blockchain-based system for creating and managing Ethereum rental agreements end-to-end (smart contracts + full-stack dApp).

#### 🧩 Smart Contract Layer  
Repository: [Rental-Smart-Contracts](https://github.com/TomerBitonn/Rental-Smart-Contracts)

- **Tech stack (blockchain & tooling):**  
  - Solidity, Ethereum (Sepolia Testnet)  
  - Hardhat (compile, deploy, verify)  
  - Ethers.js (scripts & contract interaction)  
  - JavaScript, Node.js, dotenv  
  - Chai (unit testing)  
  - MetaMask, Etherscan (deployment & verification)

#### 💻 dApp Layer (Frontend + Backend)  
Repository: [Rental-dApp](https://github.com/TomerBitonn/Rental-dApp)

- **Tech stack (full-stack Web3):**  
  - **Frontend:** React, Vite, Ethers.js, SIWE (Sign-In With Ethereum), MetaMask  
  - **Backend:** Node.js, Express.js, JWT, CORS, dotenv  
  - **Database:** MongoDB & MongoDB Atlas  
  - **Blockchain:** Ethereum / Sepolia (interacts with Rental-Smart-Contracts)  
  - **External APIs:** CoinGecko API (ETH/USD price conversion)
